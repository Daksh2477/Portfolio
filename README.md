# Daksh Parmar — Personal Portfolio

A personal developer portfolio showcasing my technical skills, projects, learning journey and interest in building practical software solutions.

This website serves as my digital introduction, bringing together my development experience, technical interests and selected work in one place.

## Overview

The portfolio is designed to present my background and development journey through a clean, responsive web interface.

It highlights my programming knowledge, web development skills and projects while providing visitors with an easy way to explore my work.

## Features

- Personal introduction and developer profile
- Technical skills presentation
- Project showcase
- Organized navigation
- Custom styling and visual assets
- JavaScript-powered interactions
- Responsive design (where supported by the implementation)
- Dedicated sections for presenting development work

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and layout |
| JavaScript | Interactions and functionality |

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Daksh2477/Portfolio.git
```

### 2. Open the project

```bash
cd Portfolio
```

### 3. Run locally

Open `index.html` in your browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension.

## Customization

You can customize the portfolio by editing:

- `index.html` — Page content and structure
- `css/` — Colors, layouts, typography and styling
- `js/` — Interactive functionality
- `images/` — Website images
- `assets/` — Supporting resources
